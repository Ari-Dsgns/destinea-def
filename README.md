# Destinea 🌍✈️

**ESPAÑOL**

**Landing page para una agencia de viajes enfocada en experiencias únicas.**  
Diseño limpio, moderno y con llamadas a la acción efectivas.  
Desarrollado por [Ari Sanpala](https://www.arisanpala.com).



## 🌐 Demo en vivo

🔗 [https://destinea.vercel.app/]

## 🧩 Descripción del proyecto

**Destinea** es una landing page diseñada para inspirar a los usuarios a explorar nuevos destinos. Presenta la información de forma clara, con imágenes atractivas, secciones bien organizadas y diseño adaptativo para todo tipo de dispositivos.

## 🎯 Objetivos

- Promocionar servicios de viajes y destinos turísticos.
- Generar leads a través de llamadas a la acción.
- Transmitir una sensación de aventura y confianza.
- Crear una experiencia agradable y rápida desde cualquier dispositivo.

## 🛠️ Tecnologías utilizadas

- HTML5  
- CSS3  
- JavaScript puro  
- Diseño responsive (Mobile First)
